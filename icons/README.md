# 아이콘 파일 안내

이 폴더에는 크롬 확장 프로그램에 사용할 아이콘 파일들을 저장합니다.

## 필요한 아이콘 파일

- `icon16.png` - 16x16 픽셀 (작은 아이콘)
- `icon48.png` - 48x48 픽셀 (중간 아이콘)  
- `icon128.png` - 128x128 픽셀 (큰 아이콘)

## 아이콘 제작 가이드

1. **디자인**: 쿠팡의 주황색 계열과 조화를 이루는 디자인
2. **형식**: PNG 형식 (투명 배경 권장)
3. **내용**: 쇼핑카트, 리뷰, 크롤링 등을 연상시키는 심볼

## 임시 아이콘 사용

아이콘 파일이 없는 경우, 브라우저가 기본 아이콘을 사용합니다.
확장 프로그램은 아이콘 없이도 정상적으로 작동합니다.
